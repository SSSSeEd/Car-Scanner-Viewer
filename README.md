# Car Scanner CSV ビューア

iPhone の Car Scanner ELM OBD2 で書き出した CSV を、ブラウザだけで読み込んで走行を読み解く Web アプリです。
CSV はサーバーに送られず、この端末のブラウザ内（IndexedDB）にだけ保存されます。

## 使い方
1. 公開URLを Safari で開き、共有メニューから「ホーム画面に追加」します。
2. 「走行データを読み込む」で、Car Scanner の CSV（または zip）を選びます。

## 表示
- **かんたん表示（既定）**: 燃費、速度帯別の燃費、月ごとの推移、距離・時間・速度など「データから言えること」を文章で表示します。
- **くわしい表示**: 暖機・急ブレーキ・天気などの診断も出します（ヘッダーのボタンで切り替え）。

## 5項目表示(father.html)
回転数・速度・トルク・出力・水温だけを大きく表示し、それぞれの最大値(と、その時刻)を出します。燃費などは出しません。
- CSV を直接選ぶか、くわしい表示で保存済みの走行をそのまま読めます。スライダーで時点ごとの値も見られます。
- トルクは CSV に列が無いため「出力(Power from MAF)と回転数からの計算値」です(回転数1000rpm未満は計算しません)。CSVに該当列が無い項目は「データなし」と表示します。

## 回転数・速度・トルク・出力・水温だけの表示
回転数・速度・トルク・出力・水温だけを、元の画面のデザインのまま表示し、それぞれの最大値(と時刻)を出します。燃費・診断・まとめは出しません。
- お父さん用リンク: `index.html?five=1`(開くとこの端末に覚えます。元に戻すときは `?five=0`)
- zip・CSV の読み込みは元のまま使えます。
- トルクは CSV に列が無いため「出力(Power from MAF)と回転数からの計算値」です(1000rpm未満は計算しません)。CSVに該当列が無い項目は「データなし」と表示します。
