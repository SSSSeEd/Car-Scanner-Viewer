# Car Scanner CSV ビューア

iPhone の Car Scanner ELM OBD2 で書き出した CSV を、ブラウザだけで読み込んで走行を読み解く Web アプリです。
CSV はサーバーに送られず、この端末のブラウザ内（IndexedDB）にだけ保存されます。

## 使い方
1. 公開URLを Safari で開き、共有メニューから「ホーム画面に追加」します。
2. 「走行データを読み込む」で、Car Scanner の CSV（または zip）を選びます。

## 表示
- **かんたん表示（既定）**: 燃費、速度帯別の燃費、月ごとの推移、距離・時間・速度など「データから言えること」を文章で表示します。
- **くわしい表示**: 暖機・急ブレーキ・天気などの診断も出します（ヘッダーのボタンで切り替え）。
